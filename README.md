# ESTER-UOPEOPLE-2026 — Caderno Acadêmico

Protótipo PWA estático para GitHub Pages.

## O que está incluído
- Painel de progresso de 20 etapas / 60 créditos.
- Disciplinas com status **Fonte oficial** ou **A confirmar**.
- Opções oficiais de General Education.
- Rotina diária flexível com estudo, corpo, mente e devocional.
- Modo foco com timer.
- Tarefas locais.
- Check-in de energia/sobrecarga e histórico.
- Reflexões devocionais locais.
- Fontes oficiais da UoPeople.
- Manifest + Service Worker para experiência PWA.

## Regra de confiabilidade
A estrutura acadêmica foi montada usando fontes oficiais da University of the People, principalmente o Undergraduate Catalog 2025/26. O site não inventa a Learning Pathway individual da estudante. A ordem real, disponibilidade e recomendações de matrícula devem ser confirmadas na conta UoPeople.

## Observação de saúde e neurodivergência
As rotinas de acessibilidade são estratégias gerais de organização, redução de sobrecarga e início de tarefas. O aplicativo não diagnostica nem trata ansiedade ou neurodivergência e não substitui avaliação ou cuidado profissional.

## Como publicar
1. Descompacte o ZIP.
2. No GitHub, abra o repositório `ester-uopeople-2026`.
3. Escolha **Add file → Upload files**.
4. Envie o conteúdo desta pasta mantendo `index.html` na raiz.
5. Faça **Commit directly to main**.
6. Aguarde o GitHub Pages atualizar.
